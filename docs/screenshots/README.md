# Screenshots

Both are 1920×1080 screenshots of a Xiaomi Mi Box S running a sample-data build: made-up calendar
events, fixed weather and the bundled BSB verse. The dock and grid show the box's own apps; their
names and logos are trademarks of their owners.

- `home-screen.jpg`: the home screen.
- `app-grid-menu.jpg`: the All Apps grid with an app's long-press menu, showing the dock cap
  ("Dock is full (6 apps)").

Both show wallpaper `01.jpg` ("1 lake louise pano 2019" by Chensiyuan, CC BY-SA 4.0).

If you add a screenshot that shows a wallpaper, credit that photo next to the image, using its entry
in [launcher/WALLPAPER-CREDITS.md](../../launcher/WALLPAPER-CREDITS.md). Avoid screenshots that show
other people's artwork, such as streaming apps' posters.
