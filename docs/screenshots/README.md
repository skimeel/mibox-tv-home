# Screenshots

- `home-screen.jpg`: the home screen on a Xiaomi Mi Box S (1920×1080), taken from a sample-data
  build: made-up calendar events, fixed weather and the bundled BSB verse. The dock shows the
  box's own apps; their names and logos are trademarks of their owners.
- `app-grid-menu.jpg`: the All Apps grid with an app's long-press menu, taken on the `tvtest_1080p`
  Android emulator with the same kind of sample data and the emulator's own apps. It is cropped to
  the 1920×1032 the launcher draws there, which keeps 48 px for a hidden navigation bar that the
  Mi Box doesn't have.

Both show wallpaper `01.jpg` ("1 lake louise pano 2019" by Chensiyuan, CC BY-SA 4.0).

If you add a screenshot that shows a wallpaper, credit that photo next to the image, using its entry
in [launcher/WALLPAPER-CREDITS.md](../../launcher/WALLPAPER-CREDITS.md). Avoid screenshots that show
other people's artwork, such as streaming apps' posters.
