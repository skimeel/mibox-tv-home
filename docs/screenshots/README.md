# Screenshots

- `home-screen.jpg`: the home screen.
- `app-grid-menu.jpg`: the All Apps grid with an app's long-press menu.

Both were taken on the `tvtest_1080p` Android emulator with sample data: made-up calendar events,
fixed weather, the bundled BSB verse and the emulator's own apps, over wallpaper `01.jpg`. They are
cropped to the 1920×1032 the launcher draws on the emulator, which keeps 48 px for a hidden
navigation bar that the Mi Box doesn't have.

If you add a screenshot that shows a wallpaper, credit that photo next to the image, using its entry
in [launcher/WALLPAPER-CREDITS.md](../../launcher/WALLPAPER-CREDITS.md). Avoid screenshots that show
other people's artwork, such as streaming apps' posters.
